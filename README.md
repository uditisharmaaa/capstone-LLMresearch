# Detecting AI-Generated Code in Introductory CS Submissions: A Multi-Model Fingerprinting Approach

A senior capstone research project at NYU Abu Dhabi investigating whether AI models leave statistically distinguishable stylistic fingerprints in student assignment code — and whether those fingerprints can reliably separate AI-generated submissions from pre-ChatGPT human work.

---

## Research Questions

**RQ1 (Complete):** Do different AI models leave statistically distinguishable stylistic fingerprints in Introduction to Computer Science assignment code, and do those fingerprints persist across 15 prompt-level style variations?

**RQ2 (Fall 2026):** Can a supervised classifier reliably separate AI-generated submissions from pre-ChatGPT student code on the same assignment?

---

## Dataset

423 Connect4 Python implementations generated by 9 LLMs across two generations, each under 15 distinct style variations:

| Model | Era | N | Directory |
|-------|-----|---|-----------|
| GPT-4o | 2024 | 70 | `data/raw/gpt4o/` |
| GPT-4o Mini | 2024 | 50 | `data/raw/gpt4mini/` |
| Claude Sonnet 3.5 | 2024 | 50 | `data/raw/sonnet/` |
| Gemini 2.0 Flash | 2024 | 50 | `data/raw/gemini/` |
| Llama 3.1 70B | 2024 | 50 | `data/raw/llama/` |
| Claude Opus 4.5 | 2025 | 28 | `data/raw/opus/` |
| o4-mini | 2025 | 43 | `data/raw/o4mini/` |
| Claude Sonnet 4.6 | 2025 | 41 | `data/raw/sonnet46/` |
| Claude Opus 4.6 | 2025 | 41 | `data/raw/opus46/` |

Generated via OpenRouter (2024 models) and NYU Portkey AI Gateway (2025 models). Two additional models (Gemini 2.5 Flash/Pro) were excluded — their thinking tokens consumed the generation budget before code output.
